làm cho tôi giao diện các trang mua hàng, thanh toán online và xửa lí thanh toán cho t đi. Một order có dạng như sau:

{
        "id": 3,
        "orderCode": "DH2025021203",
        "amount": 1800.0,
        "transactionCode": "TXN00003",
        "status": "CANCELLED",
        "createdAt": "2025-02-12T14:00:00Z"
    },

và có các routes như hình. Luồng hoạt động ban đầu sẽ là khi người dùng bấm thanh toán sẽ tạo Order với status pending. khi đến bước thanh toán thì sẽ gọi vào 
{{BASE_URL}}/payment/qr?orderId={order id}

thay cái order id thành id của order vừa tạo ở pending, kết quả được trả về sẽ có dạng như:

{
    "amount": 1800.0,
    "transactionCode": "TXN00003",
    "qrUrl": "https://qr.sepay.vn/img?acc=VQRQAELYF2308&bank=MBBank&amount=1800&des=TXN00003"
}

hiển thị thông tin đó ở fe, cái hình là get ở qrUrl là nó ra á, nhúng vào web. Sau đó thì sẽ kéo API ở: {{BASE_URL}}/check-transaction?txnCode={transaction code ở trên}
để check trạng thái {
    "found": true,
    "message": "đã phát hiện giao dịch mã 2. đơn hàng đã được thanh toán"
}

Kéo như vậy liên tục lặp lại mỗi 3s trong 5 phút. sau 5p thì coi như giao dịch bị hủy. Check kết quả found = true thì sẽ là thanh toán thành công, còn nếu found = false thì vẫn chưa thanh toán thành công. Nếu thành công thì sẽ completed và hiển thị hiệu ứng thanh toán thành công và qua trang khác, thất bại thì sẽ cancel order. Code clean code và tối ưu UX UI cho giao diện đi
